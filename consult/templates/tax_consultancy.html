Tax Consultancy API

What is this?

This page uses a custom Tax Consultancy API built in Django. The API returns JSON-based tax tips for different categories like Income Tax, GST, Investment & Savings, and Business Tax.

You (or other apps) can consume the API at: 

GET /restapi/api/tax-advice/
GET /restapi/api/tax-advice/?category=income_tax
GET /restapi/api/tax-advice/?category=gst
GET /restapi/api/tax-advice/?category=investment
GET /restapi/api/tax-advice/?category=business_tax

How to use this API?

You can use tools like Postman or your browser to check the JSON output.

  • All tips: http://127.0.0.1:8000/restapi/api/tax-advice/
  • Only Income Tax: http://127.0.0.1:8000/restapi/api/tax-advice/?category=income_tax
  • Only GST: http://127.0.0.1:8000/restapi/api/tax-advice/?category=gst
